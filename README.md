# BONICOLOR — React demo

Премиальный одностраничный демо-сайт салона Bonicolor (Казань).

## Запуск

```bash
npm install
npm run dev
```

Сборка production:

```bash
npm run build
npm run preview
```

## Что внутри
- React + Vite
- Framer Motion: анимации появления, галерея, отзывы, прогресс прокрутки
- Адаптивная верстка для desktop / tablet / mobile
- Галерея с фотографиями из публичной карточки Bonicolor в Яндекс Картах
- Отзывы, кратко оформленные на основе отзывов в Яндекс Картах
- Встроенная карта Яндекса и внешняя ссылка на карточку / маршрут
- Кнопки записи открывают WhatsApp с готовым сообщением

## Источники
- Карточка: https://yandex.ru/maps/org/bonicolor/195760941171/
- Отзывы: https://yandex.ru/maps/org/bonicolor/195760941171/reviews/

Фотографии и отзывы принадлежат их авторам и отображаются в демо со ссылкой на исходную карточку Яндекс Карт. Перед публичным коммерческим запуском следует согласовать использование материалов с владельцем салона и проверить актуальность контактных данных, услуг и цен.

Цены намеренно не указаны: карточка содержит устаревшие/неполные позиции, поэтому точную стоимость лучше уточнить у салона.
